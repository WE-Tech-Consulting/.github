# .github

ค่าเริ่มต้นของ community health files สำหรับทุก repository ในองค์กร

- `.github/ISSUE_TEMPLATE/`: แบบฟอร์ม issue ใช้กับทุก repository ที่ไม่มีโฟลเดอร์ `.github/ISSUE_TEMPLATE/` ของตัวเอง
- `.github/pull_request_template.md`: PR template กลาง ใช้กับ repository ที่ไม่มี PR template ของตัวเอง
- `SECURITY.md`: นโยบายการรายงานช่องโหว่

repository นี้ต้องเป็น public ตามข้อกำหนดของ GitHub ห้ามใส่ข้อมูลลูกค้า ชื่อโปรเจกต์ หรือข้อมูลภายในใดๆ
ถ้า repository ใดสร้างโฟลเดอร์ `.github/ISSUE_TEMPLATE/` ของตัวเอง แบบฟอร์มกลางทั้งหมดจะไม่ถูกใช้กับ repository นั้น
